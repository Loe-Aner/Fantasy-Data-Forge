## ⚔️ WoWPoPolsku 2.0

Największy z moich prywatnych projektów - setki osób na Discordzie, tysiące pobrań addonu.
Cel: nowoczesny ekosystem do przygotowania wysokiej jakości **polskiej wersji językowej World of Warcraft**.

Zaczęło się od bazy danych, skryptów ETL i eksperymentów z tłumaczeniem - *to właśnie znajdziesz w tym repo*. Dziś to system obejmujący dane, backend, aplikację webową, AI, automatyzację i integrację z grą.

**Pipeline tłumaczeniowy** - AI jest narzędziem wspierającym proces, nie źródłem prawdy:

```text
Tekst źródłowy → Kontekst (NPC/quest/świat) → Słowniki i reguły
      → Translator LLM → Editor LLM → Walidacja → Judge
      → Redakcja człowieka → Akceptacja → Publikacja
```
